# Job Market Analysis | SQL & Power BI

## Project Overview

This project was completed as part of my DataMites Data Analytics internship.

The objective was to analyze job market data to understand hiring demand, job roles, salary patterns, technical skill requirements, and differences across industries and locations.

I used **MySQL** for data exploration and analysis and **Power BI** to create an interactive dashboard for presenting key findings.

## Dataset Overview

- **Total Records:** 742 job listings
- **Total Features:** 42
- **Domain:** Job Market Analytics
- **Tools Used:** MySQL, SQL, Power BI

## Project Objectives

- Analyze job opportunities across different job roles and locations.
- Identify commonly required technical skills.
- Explore salary differences across job categories.
- Understand hiring patterns across companies and industries.
- Develop an interactive dashboard to communicate analytical findings.

## Tools & Technologies

| Tool | Purpose |
|---|---|
| MySQL | Data exploration and SQL analysis |
| SQL | Filtering, aggregation, grouping and comparisons |
| Power BI | Interactive dashboards and visualizations |
| Power Query | Data preparation for reporting |

## Project Workflow

1. **Data Understanding:** Reviewed the dataset structure and available features.
2. **Data Quality Checks:** Examined missing values, repeated records and data limitations.
3. **SQL Analysis:** Used SQL queries to explore job roles, skills, locations, industries and salary estimates.
4. **Dashboard Development:** Created a three-page interactive Power BI dashboard.
5. **Reporting:** Summarized findings, limitations and practical recommendations.

## Power BI Dashboard

The dashboard consists of three pages:

### 1. Job Market Overview
Provides an overview of job opportunities, hiring companies and job distributions.

### 2. Market & Skills Analysis
Explores job roles, technical skill requirements and industry-level patterns.

### 3. Salary Analysis
Examines salary estimates across selected job characteristics and categories.

## Key Analysis Areas

- Job demand by role and location
- Technical skill requirements
- Company and industry distribution
- Salary comparisons
- Education-related salary differences
- Data quality and analytical limitations

## Project Limitations

- The dataset represents the available job listings and should not be treated as the entire job market.
- Without a documented time variable, changes in hiring demand over time cannot be reliably measured.
- Missing or unspecified values may affect some comparisons.
- Salary estimates should not be interpreted as guaranteed compensation.
